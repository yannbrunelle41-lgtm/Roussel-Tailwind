**Intégration de la maquette Figma Fleurs Roussel avec Tailwind CSS**

**Technologies utilisées :** 
- HTML
- Tailwind CSS v4
- npm & Node.js
- CLI Tailwind

**IDE utilisé pour l'intégration :**
- VS Code avec Live Server en extension

**Prérequis et installation :**
1. Installer Node.js et npm (lien de téléchargement : https://nodejs.org/en/download)
2. Sur GitHub https://github.com/yannbrunelle41-lgtm/Roussel-Tailwind :
3. Télécharger le dossier ZIP du projet : cliquer sur "Code" puis "Download ZIP"
4. Décompresser le dossier
5. Ouvrir le dossier dans votre IDE
6. Ouvrir un terminal à la racine du projet ou se trouve le fichier package.json obtenu après l'étape 1.
7. Exécuter la commande `npm install` pour installer les dépendances
8. Exécuter la commande `npm run build` (génère le CSS minifié - production d'un CSS compact qui supprime ou réduit les éléments inutiles au navigateur. Le terminal n'a pas besoin de rester ouvert quand la compilation est réalisée)
9. Ouvrir "index.html" avec un navigateur

**Développement et modifications du code :**
1. Ouvrir un terminal à la racine du projet
2. Exécuter la commande `npm run dev` (surveille les fichiers et régénère automatiquement le CSS après enregistrement des modifications. Le terminal doit rester ouvert.)


**Contexte :**
Projet réalisé dans le cadre du brief "De la maquette à la page avec Tailwind" sur Simplonline.co.
La maquette Figma Fleur-Roussel ainsi que les images et icônes ont été fournies dans le cadre du brief.
Dans ce cadre, les liens sont fictifs. Les boutons sont cliquables mais ne font aucune action.
Liens fonctionnels pour les liens qui vont vers index.html (logo Fleurs Roussel dans le Header et le Footer) ainsi que pour l'adresse (lien Google Maps) et le numéro de téléphone qui compose le numéro fictif.
